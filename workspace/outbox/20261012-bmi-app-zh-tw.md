## 完成項目檢驗

1. **單檔離線架構**：
   - 包含完整 HTML、CSS 與 JavaScript，無引用外部函式庫，不需要網路連線即可運作。
2. **介面純繁體中文（台灣用語）**：
   - 標題：「BMI 計算器」
   - 輸入項：「身高（公分 / cm）」、「體重（公斤 / kg）」
   - 按鈕：「計算」、「重設」
   - 數值與分類：「BMI 數值（保留一位小數）」、「體位狀態」
3. **台灣衛福部 BMI 標準與顏色提示**：
   - 過輕：BMI < 18.5（藍色標籤，附營養建議）
   - 正常：18.5 ≤ BMI < 24（綠色標籤，附保持建議）
   - 過重（微胖）：24 ≤ BMI < 27（橘色標籤，附運動建議）
   - 肥胖：BMI ≥ 27（紅色標籤，附醫療與體重管理建議）
4. **防呆與異常處理**：
   - 空白、非數字、負數或極端不合理數值均會顯示台灣用語錯誤訊息（例如「請輸入有效的身高數值（例如：170）」），且不會造成崩潰。
   - 支援 Enter 鍵快速觸發計算。
