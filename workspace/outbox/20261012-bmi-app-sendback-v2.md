## 修正項目確認（已修正並回讀檢驗）

1. **無障礙（Accessibility）強化**：
   - 錯誤訊息區塊加上 `role="alert"`。
   - 結果卡片加上 `aria-live="polite"`，方便螢幕閱讀器朗讀。
   - 當計算出錯時，將焦點（focus）自動移至第一個有問題的輸入框，並加入 `aria-invalid="true"`（使用者重新輸入或重設時自動移除）。
2. **具體錯誤訊息（分情況處理）**：
   - 空白或非數字：顯示「請輸入數字（例如：170 / 65）」。
   - 小於等於 0 或負數：顯示「數值必須大於 0」。
   - 低於合理範圍（例如身高 < 50 或體重 < 10）：顯示「數值過小，請確認單位是否為公分／公斤…」。
   - 高於合理範圍（例如身高 > 250 或體重 > 300）：顯示「數值太大，請確認單位是否為公分／公斤…」。
3. **合理輸入區間更新**：
   - HTML 標籤同步設定 `min="50" max="250"`（身高）與 `min="10" max="300"`（體重），JavaScript 端亦精準校驗。
4. **無 Regression 檢驗**：
   - 輸入正常身高 170、體重 65，仍維持精確顯示「BMI 22.5 → 正常」，綠色標籤與衛福部標準建議均運作正常。
